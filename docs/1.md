Timeline Narrative Analyze 整体方向正确，
允许进入 execute。

但 execute 前补充 5 个长期边界：

1.
NarrativePhase
不是 RuntimeState。

禁止承担：
- lifecycle authority
- transition authority
- execution semantics

NarrativePhase
仅用于：
storytelling grouping。

2.
TimelineNarrativeGroup
不要存：
duration: string

改为：
durationMs?: number

UI 层自行 format。

避免：
presentation formatting
污染 projector。

3.
Narrative title
必须 anchored to real RuntimeEvent。

禁止：
synthetic AI behavior narration。

例如：
允许：
"开始执行"

禁止：
"AI 正在深度分析问题"

4.
Compression
不要按：
>=3 events
>硬编码。

改为：
significance-based folding：

- milestone → never fold
- failure → never fold
- minor/minor/minor → fold

避免 phase-count-driven UX。

5.
Timeline
不是：
AI reasoning theater。

Narrative
必须始终：
anchored to RuntimeEvent。

禁止虚构：
AI 思考 / 推理 / 规划过程。

在以上边界下，
允许进入 execute。
