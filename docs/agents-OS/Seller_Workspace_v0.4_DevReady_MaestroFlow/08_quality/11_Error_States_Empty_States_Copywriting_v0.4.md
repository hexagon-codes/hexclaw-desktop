# 11 Error States / Empty States / Copywriting v0.4

## 1. 激活页

| 场景 | 文案 | 操作 |
|---|---|---|
| 首次打开 | 请复制设备码发给管理员，获取激活码后输入。 | 复制设备码 |
| 激活码为空 | 请输入激活码。 | 聚焦输入框 |
| 激活码无效 | 激活码无效，请检查后重试。 | 重新输入 |
| 激活码过期 | 激活码已过期，请联系管理员续期。 | 联系管理员 |
| 已绑定其他设备 | 该激活码已绑定其他设备，如需换绑请联系管理员。 | 联系管理员 |
| 网络错误 | 网络异常，请稍后重试。 | 重试 |

## 2. Chat 首页

| 场景 | 文案 | 操作 |
|---|---|---|
| 空状态 | 你可以直接描述任务，例如“帮我把这批商品图生成详情图”。 | 上传/输入 |
| 未上传素材 | 请先上传至少一张商品图。 | 打开上传弹层 |
| 识别不确定 | 我还需要确认这些素材的用途。 | 显示资产确认卡 |
| 缺少参数 | 为了开始任务，请补充以下信息。 | 显示参数卡 |
| 无 Skill 权限 | 当前激活码暂不包含该 Skill，请联系管理员开通。 | 联系管理员 |

## 3. 上传

| 场景 | 文案 | 操作 |
|---|---|---|
| 文件过大 | 文件过大，请压缩后重试。 | 重新选择 |
| 类型不支持 | 当前暂不支持该文件类型。 | 移除文件 |
| 目录为空 | 该目录中没有可用素材。 | 重新选择 |
| 部分失败 | 部分文件添加失败，其余文件仍可继续使用。 | 查看失败列表 |

## 4. 任务执行

| 场景 | 文案 | 操作 |
|---|---|---|
| queued | 已创建任务，等待执行。 | 无 |
| running | 正在生成，请保持网络连接。 | 取消任务 |
| provider_timeout | 图片生成超时，请稍后重试。 | 重试 |
| provider_failed | 图片生成失败，请稍后重试。 | 重试/联系管理员 |
| cancelled | 任务已取消。 | 重新开始 |
| succeeded | 已完成。 | 下载/导出/重新生成 |

## 5. 后台

| 场景 | 文案 |
|---|---|
| Schema 非法 | JSON Schema 校验失败，请修正后保存。 |
| Skill 停用确认 | 停用后用户端将无法执行该 Skill，是否继续？ |
| 激活码生成成功 | 已生成激活码批次，可导出或复制。 |
| 激活码重复异常 | 激活码生成冲突，请重试。 |
| 设备解绑确认 | 解绑后原设备将无法继续使用，是否确认？ |
