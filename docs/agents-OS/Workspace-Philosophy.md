# Workspace Philosophy

> 定义：
> 为什么不是低代码平台
> 为什么不是后台管理系统
> 为什么是 AI-native Workspace

---

# 一、系统定位

本系统：

不是：

- ChatBot
- Workflow Builder
- BPMN 平台
- Admin 后台

而是：

# AI-native Workspace

---

# 二、为什么不是低代码平台

低代码平台：

核心：

是：

- 节点
- 编排
- 流程图

---

# 本系统：

核心：

是：

- Task
- Runtime
- Context
- Skill

---

# 三、为什么不是插件平台

插件：

本质：

是：

功能扩展。

---

# Skill：

本质：

是：

经验系统。

---

# 四、为什么不是后台系统

传统后台：

核心：

是：

- CRUD
- 菜单
- 权限
- 表格

---

# AI-native Workspace：

核心：

是：

- Task
- Timeline
- Context
- Asset

---

# 五、Workspace 核心结构

```txt
Chat Workspace
Task Runtime
Runtime Timeline
Asset Workspace
Skill Runtime
```

---

# 六、Chat 的角色

Chat：

只是：

Task 入口。

不是：

系统核心。

---

# 七、Timeline 的角色

Timeline：

是：

Runtime Execution History。

不是：

聊天记录。

---

# 八、Asset 的角色

Asset：

是一等公民。

包括：

- 图片
- 视频
- SKU
- 文件

---

# 九、Skill 的角色

Skill：

是：

Experience Package。

不是：

插件。

---

# 十、最终目标

构建：

# Local-first AI-native Workspace

而不是：

# AI Workflow Platform
